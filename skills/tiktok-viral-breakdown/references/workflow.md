# 内容分析方法

## 顺序

输入 → 核对素材身份 → 信息/口播/关键帧/OCR → 时间轴 → 内容机制 → 报告。
先看工具warning与内容完整性；用户现成资料无需重新提取。

按内容变化分段：新动作、卖点、疑问、测试、结果、CTA。短视频可以只有3–5段，长视频合并重复动作。先完整理解，再压缩输出。

## 七个判断

1. Hook：视觉、口播、字幕哪个先产生作用？定位具体时间和内容，判断结果前置/痛点/反差/反常识/动作前置/测试悬念。说明观众在期待什么。
2. 痛点：功能（掉色/脱落）、操作（不会贴/耗时）、效果情绪（显假/不适合肤色）。逐一对应视频回应，不堆人群标签。
3. 视听协同：说防转印时是否展示接触物和唇部？说简单时是否完整演示？展示产品时是否说明名称？无音频访问不写音乐结论。
4. 节奏：期待建立→递进→测试→奖励→行动；重复内容是强化、教学还是拖沓？长视频中闲聊/失焦可以增加真实感，也可能拖慢节奏，不一律包装成优势。
5. 信任：过程、结果、测试、经历、品牌/他人背书分别提供多强证据？当次洗脸不证明7天持久，博主说无剪辑不证明全片连续。
6. 爆点：找一个最关键转折，给实际时间和机制。多角度成品不等于功效验证，文案参数不等于画面同步出现。
7. 公式：抽象为可迁移关系，比如“结果前置＋低门槛解释＋现场证据＋情绪收益＋CTA”；视频没有CTA就不补。

## 采样建议，不是时间轴证据

标准初看约12帧，轻量约6帧，展示约8帧。长度、动作变化可调整；开头3秒、测试和结尾优先。对一秒内的揉嘴、擦拭等动作补密集采样，不以低密度帧证明连续性。长片分段，不能把最多60帧误称全片逐秒观看。

## 效果评价

标准互动率 = (点赞+评论+分享)/播放量×100%。含收藏互动率再加入收藏。
这是互动描述指标，不是成交率、留存率，也不应跨类目机械比较。不知道分发量或投流情况时不确定归因。
